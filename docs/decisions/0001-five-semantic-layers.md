# ADR-0001：采用五层语义事实组织方案

状态：Accepted（仅下述范围）。日期：2026-11-01。

## 决策依据

用户在本会话明确要求“采用五层的方案”。本项目按DDD与OpenSpec/Superpowers开发；这不是对所有候选设计细节的批准。

## 已确认内容

| 层 | 名称 |
| --- | --- |
| E0 | 工程组织与协作 |
| E1 | 构建装配与交付 |
| E2 | 程序结构与接口 |
| E3 | 操作行为契约 |
| E4 | 实现算法与局部语义 |

五层作为语义组织尺度，不构成强制包含树或自动细化链；主体保持单一身份，跨层通过类型化引用关联。DDD用于统一语言、身份和不变量，不将DDD实现职责当作语义层。

## 未随此决策批准

全部谓词/字段、身份编码、语法与操作语义、聚合与限界上下文、实现语言、数据库、解析工具及全部候选验收结论。宏展开、注解、多workspace、循环和完整来源覆盖仍需后续证据。
