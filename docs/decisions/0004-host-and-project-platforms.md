# ADR-0004：Skill宿主、分析工具与被分析项目的平台

状态：用户已明确确认。日期：2026-11-02（Asia/Shanghai）。

## 确认依据

用户原文：

> Host，Skill的宿主可能运行在windows, Linux，MacOS等操作系统，分析工具与Skill运行期的平台一致。
> 分析项目的平台，与其设定的构造/编译环境相关。

## 确认定义

- host指Skill宿主运行的平台，可能为Windows、Linux、macOS等；分析工具的运行平台与Skill运行期平台一致。
- 被分析项目的平台依据该项目设定的构造／编译环境确定，不按Skill的host直接推定；二者可以不同。

本次仅固化上述定义。没有据此增加“必须同一进程/同一机器”的限制，也没有把平台示例当作所有OS版本、架构、工具或交叉编译组合均已验证。D01的这些具体组合、语言版本/混合边界及负载仍需收敛；D02/D03不变。未批准产品开发或归档。
