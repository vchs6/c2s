# ADR-0006：单次分析期间项目保持不变

状态：用户明确确认。日期：2026-11-02（Asia/Shanghai）。

## 确认依据

用户原文：“每次分析过程中，项目不会发生任何变更”。

## 确认范围

一次分析期间，项目输入保持不变。分析可以按查询逐步取得事实；查询所需内容、已构造内容、已存内容和证据覆盖会增加，但这不表示项目源码正在变化。

因此本期分析内的增量是补充尚未构造/存储的内容，不要求处理分析进行中的源码热更新、更新传播或来源变化刷新。D03关于“构造和提交之间项目变化”的前置裁决在该边界内不再适用。

## 不作额外推定

这句话没有确认不同分析次数之间项目永远不变，也没有选择跨次结果复用、更新、删除或历史版本政策。跨次策略保留为独立讨论，不作为同次固定输入按需补充流程的阻塞；不自动选择先前A/B/C任一更新方案。

实施方式仍是候选：可标记成果所属分析输入与适用上下文，复用时保持该归属和语义条件；不因本决定强制实现项目文件锁、持续全仓监控、每查询重新全量校验或用户快照服务。已知输入归属不一致时不得盲混结果；不以此扩大为热更新能力。取消、失败重试、并发重复提交和引用完整性仍需规划。

本次不批准产品开发、不运行产品分析、不归档。
