# ADR-0012：以语义实体为中心组织项目事实

状态：Accepted（仅限本文范围）。日期：2026-11-07。

## 背景

既有公共模型以 E0–E4 观察尺度和源码声明为主要组织方式。用户确认项目分析的目标是从源码、少量说明、测试及工具证据逆向推导项目目的、能力、数据、计算和关系；类、字段、函数、枚举、宏、泛型及其他语言构造是实现参考，不能直接替代这些语义对象。

## 决策

公共领域模型以有稳定身份的语义实体、实体属性、类型化关系、事实主张、证据、覆盖状态、源码构造、实现映射和测试验证关系为核心。项目和模块也属于语义实体。E0–E4 保留为可组合的事实观察视角，不决定实体类型、业务边界或包含关系。实体身份由指定分析范围内的持久注册表分配和复用；来源变化不能仅凭名称或路径合并实体。

实体详情完整返回该实体自身全部已取得属性；子实体只按请求展开。源码构造及其语法/语言机制通过显式映射解释如何实现语义实体；未能映射的构造与缺口仍保留。测试对象与测试入口、测试目标分别建模。无证据的语义解释不得作为已确认事实。

迁移采用新版本模型档案与旧版确定性兼容投影。全量验证前保留旧默认写入路径；全量验证后新档案成为唯一默认写入，旧完整档案只读，M1 入口保持独立。不得以实体名称、路径或源码类别猜测旧数据映射。

## 对既有决策的精确替代

- 本决策及 `semantic-fact-model` 新规格替代 ADR-0001 和既有 `semantic-fact-model` 规格中“E0–E4 是语义事实的主组织轴”这一模型组织选择。E0–E4 的五种观察尺度、层名与不构成强制包含树的规则继续有效。
- 本决策及 `semantic-fact-query` 新规格替代 ADR-0007 与既有查询规格中将类、类型成员等源码类别作为查询对象主分类的表达方式。ADR-0007 已确认的按请求定位顶层对象、只返回请求范围、同主体增量补充、双格式输出和缺口如实报告继续有效。
- 本决策及 `lazy-semantic-fact-construction` 新规格替代既有按源码主体身份复用分析内容的表述，改为按稳定语义实体身份及适用覆盖复用；源码构造仍是独立实现参考。
- 不更改 ADR-0002 至 ADR-0011 中与上述范围无关的确认、环境约束和工作纪律；不追溯改写既有决策记录。

## 后果

需要新增版本化实体契约、身份注册表、关系与证据校验、源码构造适配器、语义映射器、隔离仓储、查询投影及旧档案兼容测试。真实项目分析必须标明发现能力边界和未解决推断，不能宣称自动完整还原业务意图。实现及迁移进度以 OpenSpec 变更 `redesign-semantic-entity-domain-model` 的任务表为准。
