# ADR-0014：移除V1公开接口

状态：Accepted，依据用户2026-11-09明确指令“不保留V1接口；进行独立的代码审核”。

本决策替代ADR-0012及重构设计中的旧运行接口兼容承诺。产品只公开V2查询、结果、校验和仓储；删除旧CLI分支、旧查询结果/缓存、M1和完整事实旧仓储、实体V1仓储、兼容查询及导入导出。固定选择器继续转成V2，不返回旧载荷。

历史Schema和已发布证据保留，历史契约回归辅助位于tests，产品不导出。V2所需共享结构规则保留为内部校验；通用算法自身schema_version=1.0.0不等于实体V1协议，保持其算法能力。

不删除用户数据库，不自动迁移或覆盖旧内容；旧档案拒绝，已有混合库只访问V2。显式完整SQLite备份仍可用于当前档案。历史版本回退需独立备份及Git版本，不提供产品内V1恢复/转换服务。

这是已确认的不兼容删除，不再次请求兼容策略批准。范围、测试、独立审核及实跑证据归原OpenSpec变更第11节，不自动归档。共享工作区的独立上下文代码审核不称私有盲验收。
