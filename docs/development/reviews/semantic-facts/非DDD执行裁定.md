# 非DDD重构执行裁定

本文件保存Superpowers执行账本中的全部Ruling及代价，替代仅存在于临时工作目录的决策记忆。任务完成证据见唯一OpenSpec任务第10节与交付核验。

1. 已有用户授权直接main提交推送，本轮沿用，不新建分支。代价：不具备分支级隔离，但未改变已授权交付方式；没有force操作。
2. Superpowers任务脚本不能解析仅导航的计划，改为以唯一OpenSpec任务10.x读取brief，手工记录真实红绿命令与提交，不复制任务。代价：账本需人工核对，不能依赖脚本自动勾选。
3. 工具分歧测试应选择calculate函数，不把AST首条module当函数；修测试选择而不改解析顺序。代价：保持前端自然顺序，调用方须明确目标。
4. v2按scope、输入指纹、配置复合键隔离；保留覆盖历史，静态部分可复用但保留原诊断，retryable/取消不满足复用。代价：保留多快照及历史占用额外磁盘；修正后的缓存也遵守该条件。
5. CodeGraph解析与真实输出通过仍保持candidate，未证明相对现有组合净收益不点亮。代价：不会自动采用其图能力；原始截断stderr完整保留。
6. execute_fact_query增加可选cache参数以接续既有API，新v2入口共用执行/投影器，旧v1直接接口保留；声明索引跳过全仓算法构造。代价：需维护显式兼容边界，不把旧v1接口冒充v2。
7. 真实项目发现implementationType:null不合法，省略未知可选字段并增加失败回归；opaque元数据保留，产品源码摘要进入配置键。代价：升级代码导致缓存miss并重取，未知类型不能被填成推断值。
8. 覆盖必须匹配目标和facets，不能以工作空间或声明覆盖满足未取得算法；诊断按所属目标投影。代价：窄查询不显示其他目标缺口，整体盘点须使用宽范围查询；避免无关诊断二次方扩张。
9. 最终代码候选与全套检查先行，独立审核修正后重新生成固定真实项目产物，旧报告不冒充最终配置。代价：延后10.10完成标记并承担额外运行成本，不减少验证。
10. Python a=b=1/import os,sys的原生Fact是分组记录，撤销错误的逐名称测试预期，保留完整原始分组观察。代价：调用方从分组原文读取成员，不制造前端未发布的多条事实。
11. 枚举值域仅在同文件词法作用域内唯一简单名解析；跨模块绑定未知时不按末段名猜。代价：有限值域覆盖更保守，避免串用其他模块的证据。

独立审核0Critical/7Important/0Minor，7项全部复现并进入一次修正；没有拒绝判断事项，没有延后Minor。上述裁定不扩大语言、目标平台、迁移方案、业务需求推导或商业工具范围。
