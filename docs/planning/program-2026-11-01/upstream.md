# 本轮上游规划结论

状态：规划启动。已选领域模型A与固定基线见context.md；尚无本期新增用户决策，不编造数值目标或支持矩阵。

## #5 质量评价（候选、非用户确认）

代表场景附风险与遗漏；所有请求计总体，部分/失败非成功，成功延迟附成功率。固定质量证据分别比较首次/热复用/变化全链路Token；语言混合、host、target分列组合证据。D01范围规模、D02目标质量基准待用户；无实测。

## #6 架构（候选）

逻辑职责分离可同进程：#3公共语义；#7规范请求/投影；#8缺口计划；#9持久化；#10获取；#12核验与执行；#5/#11评价。命中非有效，未核验/失败/变化单列；扩取有理由不越界返回。允许轻量定位索引，不预构造全仓具体语义。核心任务只契约端口，不重复下游算法。

## #7 查询（候选）

结构化规范核心，可选自然语言解释；歧义依赖阻塞，独立项可部分完成。状态正交、否定有界证据。根0授权有向边1，定义去重不吞显式有限路径或其他路径余深度；无界闭包不默认允许。kind最小投影表待#3目录一起冻结，不能全属性替代。

## #8 延迟构造（候选）

缺口驱动有理由依赖；响应深度非内部依赖上限。定位索引不得预推具体语义；复用核身份/来源/配置/host-target/能力规则版本/覆盖。循环无进展或限额保持未决；单订阅取消不伤共享，发布未定不可复用。#8计划，#9发布，#12执行。

## #9 增量存储（候选）

主体身份不变；相同主张/新证据/不同条件/冲突/来源变化分开。确定性判重，跨操作ID去重、同ID异内容拒绝；循环引用自洽单元共同发布。补证不含撤证，覆盖不能简单合完整。D03 A显式更新当前有效集合（建议）vs B严格新增、只响应失效待显式重建，均待用户，历史服务不默认加。
