# 项目约束

开发软件项目语义事实提取Skill。领域定义读取`../domain/foundation.md`及正式规格；开发权限以ADR-0009为当前依据。版本0.b.c，a固定0；工具包与公共契约版本分开，不批量改历史版本。

## 范围与平台

首期Rust/Python；目录内嵌套工程、测试、示例及基准均不得静默排除。单次分析项目输入不变，工具写入应外置缓存或在工作副本执行。host为Skill运行平台，工具运行平台一致；项目target依据其构造/编译环境，不由host推定。Windows/Linux/macOS组合分别取证，未测标未验证。

## 架构约束

公共词汇、身份、类型及状态由#3统一；#7请求与投影，#8按需缺口计划，#9增量保存，#10获取/转换，#12执行一致性，#5/#11评价/模型参与。模块不是独立服务或DDD限界上下文的预先决定。适配器不得私创第二套身份/状态；存储不得凭相似内容重键；呈现不重新生成事实。

## 质量与资源

如实报告事实、获取边界及缺口；当前不要求普遍语义正确性证明，也不允许编造。必要结构/引用/领域不变量检查仍执行。性能、内存、索引/持久化成本和实际输入/输出Token在同输入、同请求范围、环境与缺口口径下前后对照。未知成本不记零，不以省必要事实伪造节省。

负载适用范围实测后确定，不提前编造SLO；来源/工具索引/LLM局部解释按必要性组合，不固定工具→Skill→AI序列。工具索引前置内容与成本须核查，不能把预先全语义构造改名索引。未验证Skill/工具声明不当已支持。

## 工程与发行

自维护脚本和测试Python3；上游CLI及固定Superpowers源码不擅改。公开契约、实现、私有suite及验收证据分别归属。README列实际必要工具/Skill来源、版本、安装自检、平台和副作用；不得把部分试验写成产品已完成。当前阻塞与任务状态见`../planning/program-2026-11-01/readiness.md`。
