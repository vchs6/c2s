# 公开复现与审核修复设计

用户已要求按外部报告和本轮比对修复，延续连续执行及main提交授权，不重复讨论已明确方向。唯一任务在既有OpenSpec变更第12节；外部附件是问题证据，建议不是自动执行指令。

公开运行支持Python3.12.x（>=3.12.0、<3.13.0），精确验证版本独立记录，不以3.12.14锁死补丁版本；环境自检与CI使用相同范围。最小依赖固定jsonschema/tree-sitter/tree-sitter-rust，导入已有图输出不要求可选工具安装，但仍要求已验证解析器及协议、路径、截断和新鲜度检查。

公开CI在干净检出中运行核心Skill单元回归，另有固定真实项目强制集成门禁；单元测试可缺少外部夹具并明确skip，集成模式缺夹具必须失败。提供可重建固定Click/regex/nlohmann-json检出的Python脚本，验证固定提交，不提交.local或第三方完整副本。npm test同时包含顶层与Skill，维护Runner同样检查核心测试。最终验证需真正不安装可选图包的独立环境，至少两个Python3.12补丁版本。

完整目录盘点和全内容输入指纹保留，不自动排除node_modules/target/隐藏路径；请求覆盖只计相关支持源码，其他路径单独分类不降低声明查询完整性。对Python源码每次解析预计算行起始字节，指纹流式读取文件以控制大文件内存；不以stat缓存冒充内容校验，不减少固定输入变更检测。

同输入/配置/目标/facets/条件的有效覆盖用稳定键更新，不把操作号附入覆盖身份。相同取得状态在模型中去重；独立操作回执仍记审计历史，不承诺所有历史表永不增长。重试成功后有效状态可更新；失败/取消不能抹掉此前已取得覆盖，不能将未完成发布完整。

SQLite连接在事务提交/回滚后显式关闭，旧档案只读探测和备份的两个连接均关闭。投影缺失证据/工件产生具体诊断，不能静默丢引用。Markdown围栏及注释不产生模块/能力候选。Bot状态采用有版本的编码载荷、完整字段校验和唯一独立标记，不把模型正文当控制状态；只接受可信Bot，评论仍不授权工作。所有Action固定到已核实提交SHA，维护检查子进程使用最小环境白名单，不发送任何测试消息到GitHub。

最终在完成所有修复后新上下文独立审核，不以作者原环境绿灯代替干净检出或公开CI结论。远程CI无法读回时明确未核实，实际执行其同等命令并保存证据，不冒称远程通过。
