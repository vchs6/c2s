# 双向独立编写环境

当前规则：ADR-0010。编码与独立验收作者双向隔离；五种职责保持所有权和独立判断，不要求全部互盲。产品开发授权已有，环境证据不足须具体报告，不能重复索批。

## 输入与输出

| 职责 | 可读输入 | 独占输出 | 禁止输入/动作 |
| --- | --- | --- | --- |
| 编码 | 固定公开需求、公共接口、设计、开发侧实现和单元测试、受控缺陷反馈 | candidate | 独立suite、断言、原始私有日志与制品、作者上下文 |
| 独立作者 | 相同公开需求/接口、固定真实分析项目、工具与目标环境 | suite | c2s候选实现、内部设计/讨论、据实现调整预期 |
| 审核 | 需求、设计、候选实现 | review | 改写candidate或代替独立作者 |
| CI执行 | 固定candidate/suite、公开契约、真实输入和工具版本 | run记录 | 改代码/期望、向编码发布原始私有输出 |
| 最终验证 | 必需的版本清单、review和run证据 | verdict | 改原始证据、自行豁免失败 |

公开Requirement/Scenario和双方共享的外部接口保持公开。真实项目源码是分析输入，不是禁止作者阅读的c2s候选实现。开发侧单元测试不能取代独立验收。

## 执行方式

AI/人工只承担需判断的设计、编写、审核、诊断。工具安装、构建、测试和版本摘要核对由固定CI执行，默认不调用模型，不需要模型密钥或API余额。仍需独立最终结论，不以脚本通过冒充语义审核。

1. 协调者冻结公共契约与任务，按白名单产生无源历史的角色仓库。
2. 正式编码和作者通过各自受限工具入口在新上下文独立产出。仅设置cwd不够；不得向双方发放协调者管理连接器或宿主shell。
3. 固定candidate/suite及契约、真实输入、工具/host/target版本。版本或摘要失配先拒绝，不能混用旧审核证据。
4. 可信CI读取双方固定输出，运行固定测试harness；候选程序不能读取suite或测试凭据。执行器不需要AI；不让候选控制workflow。
5. 完整输出留执行/验证区。编码仅收公开条款和经筛选的必要缺陷；新增公开回归用例须经过披露判断，不能直接同步隐藏用例。
6. 独立审核与最终验证产生各自结论后协调者按原tasks推进；不自动归档、不由Issue启动。

## 已部署入口和验证

`prepare_role_repositories.py`只准备公开实验快照，不是任意产品文件同步或权限broker。`private-access-check.yml`已有托管worker边界证据；新增`blind-development-check.yml`聚焦coding/author及固定公开交接验证。命令和精确通过范围以相应workflow和执行报告为准。所有合成材料公开，不包含真实独立用例。

公开环境自检：`python3 scripts/check_public_environment.py`。维护检查：`OPENSPEC_TELEMETRY=0 npm run validate`、`npm run check:artifacts`、`npm test`。托管probe使用Ubuntu24.04、Python3和Git，宿主Docker只由可信固定脚本调用，镜像按实际RepoDigest执行；运行镜像获取需网络，受限worker不联网、不接收认证。当前未证明Windows/macOS角色执行环境；不外推。

正式AI角色入口与真实suite交接尚未部署验证。当前原生代理仍共享广权限，不能用它编写真正隐藏用例，也不能宣称本文件提供了强制工具代理。模型订阅/API认证属于编写入口配置，不能通过复制宿主认证或给模型Docker权限解决。公开probe不能替代真实模型工具旁路检查。

## 证据与恢复

记录源commit、workflow/run、角色、镜像digest、输入摘要、结果和未运行部分。失败不扩大权限、不调整期望；修复后只重跑受影响检查，变更版本须使旧结论失效。停止有问题的模型入口仍可继续公开准备和无需模型的CI。
