# 决策管理

| 类型 | 权限及记录 |
| --- | --- |
| 用户明确确认 | 保留原文、上下文与范围，固化到相应正式规格/ADR；不额外推导实施或范围批准 |
| 已委托技术选择 | 代理以事实与反例裁定，记录理由、影响及可证伪条件；不冒称用户逐项确认 |
| 候选/研究结论 | 保持候选状态，文档能力、源码检查、实际运行分开；不自动同步主规格 |
| 重大变更 | 改变已确认行为/身份/边界、不相容承诺、重要资源取舍或无依据可裁的矛盾，提交具体备选/推荐/证据及影响，等待用户决定 |

发现矛盾先给具体Requirement/场景/反例，不静默覆盖；影响哪些规格、设计、任务及证据一并列明。不得通过更改测试期望迁就实现。领域已确认不因尚未实现而重开。

当前开发授权成立（ADR-0009），准备门禁未过不意味着需要重新索取开发批准。环境缺能力属于执行阻塞，写入readiness和原任务，不伪装领域决策或擅自降级隐藏测试约束。
