# Spec Delta

## Purpose

为软件项目语义事实查询规定响应范围和展开边界，使用户能够取得符合请求的顶层最小事实集，并在明确要求时展开指定内容，同时区分呈现时未展开与事实尚未获取等不同情况。本规格固定行为，不固定请求字段、响应编码或获取流程。

## ADDED Requirements

### Requirement: 查询限定响应事实范围

系统 SHALL 以响应用户查询为目的，仅返回符合查询请求的事实信息。系统 MUST 按请求确定响应对象与范围，不因已有额外事实而自行扩大响应。确认依据：B04，见`docs/decisions/0002-confirmed-specification-baseline.md`确认矩阵。

#### Scenario: 已有事实多于请求所需
- **WHEN** 用户仅请求某个项目的顶层信息，已有事实还包含其他对象及更深层实现
- **THEN** 响应仅包含符合本次请求的信息，不自动附送其他对象或完整实现事实

### Requirement: 默认顶层最小事实集

系统 SHALL 默认只返回符合请求的顶层最小事实集；没有用户明确展开要求时 MUST NOT 递归展开组成项或沿关联继续展开。顶层相对于本次查询对象确定，不表示永远只返回E0。确认依据：B04。

#### Scenario: 查询操作而未请求展开
- **WHEN** 用户查询一个操作的顶层信息，未要求展开其算法或相关操作
- **THEN** 返回该操作符合请求的顶层信息，不递归展开算法步骤或相关操作

#### Scenario: 查询项目而未请求展开
- **WHEN** 用户查询项目的顶层信息，未要求展开组成内容
- **THEN** 不因项目存在构建目标、模块和操作事实而递归输出它们

### Requirement: 按明确要求展开

系统 SHALL 仅在用户明确要求时，按请求指定的对象、关系或深度展开事实；MUST 保持请求的展开边界，不能把一次展开授权解释为无限展开。请求表达的具体语法不在本基线中固定。确认依据：B05。

#### Scenario: 只展开指定对象
- **WHEN** 用户明确要求展开某一对象，未授权继续展开其关联对象
- **THEN** 只展开请求指定的内容，不沿其他关系继续递归

#### Scenario: 指定展开深度
- **WHEN** 用户明确指定展开深度
- **THEN** 在该深度边界内响应，不自行继续展开

### Requirement: 未展开与获取状态可区分

系统 SHALL 区分因响应边界而未展开、尚未获取、已确认不存在、不支持和不适用；MUST NOT 仅凭响应未展示或字段为空，将其他情况报告为不存在。本基线不固定这些区别的字段名或枚举编码。确认依据：B06。

#### Scenario: 已获取内容未展开
- **WHEN** 子事实已获取，但用户没有要求展开
- **THEN** 该内容可表达为未展开，不标为未获取或不存在

#### Scenario: 尚未获取与不支持
- **WHEN** 请求内容尚未获取，或当前能力不支持获取
- **THEN** 区分这两种情况，不以空结果声称内容已确认不存在，也不将不适用混作未获取
