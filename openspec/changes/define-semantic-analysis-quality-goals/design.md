# Design

## Context

2026-11-02更新：用户已明确首期源语言Rust和Python（ADR-0003）；D01仅语言这一维已决，版本/混合边界/host/target/负载仍待定，其他设计和指标仍是候选。

已确认目标见共享context；#5两轮Battle及独立复核见对应评审目录。没有运行测量、支持验证或具体负载承诺。用户确认与候选分开。

## Goals / Non-Goals

评价语义正确性、证据、查询延迟、构造成本、存储效率、一致性、扩展性、可观测和可维护性。非目标：设定未经确认的SLO、宣称全部组合支持、重开语句级粒度。

## Decisions

候选：代表工作负载加失效风险映射，替代全语言×平台×规模穷举；穷举覆盖更强但组合膨胀，代表样本不得外推未测组合。档案至少含输入快照、对象数量/源码规模、请求与展开范围、并发/变化比例、工具与模型版本、host/target、缓存状态及质量判定依据。场景覆盖首次顶层、显式展开、已有读取、重复请求、局部变化、跨项目、混合语言边界、工具缺失和失败。

授权范围内代理决定：质量不合格、超时、部分和不支持仍进入全部请求分母；成功延迟同时报告成功率，首结果含缺口不等于完整成功。完整成功相对于请求与证据，不是全仓全层完整。

Token比较固定输入、语义范围、证据质量和环境，分别列直接模型、确定性转换和局部模型补足；分冷/热/变化，计输入/输出Token、调用数、模型上下文量及重复分析。构造、复用维护、失败重试和响应成本不能转移漏计。实际收益必须未来测量，非从热命中推断冷启动收益。

质量基准需要人工可审查的期望事实与来源，争议事实单列；支持矩阵分别登记语言版本/混合边界、host、target和组合证据。未知、不支持、未测分开。

计时口径：从入口接受请求开始，首结果截止首个可用且带范围/缺口的语义结果（仅ack不算）；完整结果截止请求范围处理结束并声明结果状态。排队、核验、工具、模型、存储及投影计入端到端；超时以接受到终止计，重试归属原逻辑请求，另列每次尝试。流式前缀不是完整成功。报告延迟分布（p50/p95/p99、样本数）、完成吞吐/成功吞吐、并发、峰值内存、工具分阶段耗时及存储写放大/有效占用；分位数不足样本时明示。目标值待D02。

## Risks / Trade-offs

代表样本漏风险：明确遗漏和待测。质量判据漂移：版本化固定样本。跨环境比较失真：不合并不等价组合。存储效率同时记录有效事实量与元数据/证据占用，不用压缩丢证据换优势。

## Migration Plan

仅规划。D01支持组合/负载规模、D02质量判据/数值目标由用户裁决，未定时只设计测量协议。下游引用本口径不代表数值达标。

## Open Questions

首期矩阵、规模、质量基准与具体目标未决；来源变化策略由#9提出。所有数值均未测量。

语义完成与持久化结果独立统计，语义成功率/成功延迟按#7满足请求语义证据判定；保存失败不会抹去已完整回答，但操作汇总为partial并计操作成功率/提交失败，#12不得用单一success吞并。相同全部请求分母报告两维分布，不需要写的有效复用标not-required。
