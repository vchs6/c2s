# Design

## Context

已确认：共享context、ADR-0001/0002和两份主规格；模型A由用户选择但未批准实施。当前无产品实现或性能实测。新设计是候选；细节由授权范围内代理提出，不成为用户确认。讨论、异议及独立复核见本Issue评审目录。

## Goals / Non-Goals

区分请求、必要构造、响应三种范围；所有既有查询Requirement有正反例。非目标：DSL/JSON Schema实现、历史查询服务或承诺自然语言入口首期可用。

## Approaches

候选结构化公共核心，可选自然语言解释后经确定性校验；替代仅结构化入口更可预测但交互成本高；全程自然语言直接驱动工具不利于边界验证且重复Token。前两者可共用核心，入口范围由D01/整体审核确定。

## Decisions

候选规范请求语义：AnalysisScope项目或项目集合选择，模型A主体引用/有界选择器，所需事实或关系，适用上下文，显式展开关系/方向/深度。名称不是身份；无法唯一解释的项目、重载或上下文返回候选与缺口，不自动选择或扩大。独立且已唯一的请求项可取得结果，依赖歧义部分不执行；整次仍报告部分/需澄清，不能成功吞并。

顶层最小集由请求对象kind和显式语义问题确定，引用模型A谓词目录；不在本提案猜每kind固定字段，目录的最小投影表需与#3一起冻结，未定义的选择器返回未解决而非自动all。引用只携身份/必要kind与条件，不内嵌完整对象。

候选展开计数：根为0，只有显式选择的关系方向每次跨一条语义边计1；不按层差计数，证据/标量不算展开边，但不得夹带关联主体定义。未指定方向/关系且存在多种解释时澄清；允许明确“该关系所有可达”时仍须有界执行策略和循环去重，首期不默许无限。循环检测按当前路径上的主体+适用上下文+关系策略控制；共享节点不同路径的剩余深度与授权分别计算，不能全局去重吞掉合法展开，重复出现的主体只返回引用/循环标记而不重复定义；遍历与定义输出分离，显式有限路径仍按授权走到指定深度，不因遇到主体就提前截断。无有限深度/明确有限路径的请求不得执行无界闭包。

逐项分别记录呈现、获取、有效性、适用、诊断和覆盖，复用模型A语义，不重定义互斥总枚举。不存在附限定范围和否定证据；冲突保留主张。错误区分请求无效/歧义、能力缺口、获取失败、取消/超时、提交失败，后四者不能变不存在。总体状态是逐项汇总，不消除细节。

| 主规格 | 正例 | 反例 |
| --- | --- | --- |
| 查询限定范围 | 请求项目A，只返A | 因已存B附送B |
| 默认顶层 | 操作签名与必要引用 | 内嵌完整算法或关联类型 |
| 明确展开 | 指定组成边深度1止步 | 沿调用再无限展开 |
| 状态可区分 | A可用、B未获取、C不支持分别列 | 空载荷统一不存在 |

跨项目同名、配置缺失和混合语言边界使用同一规范请求语义，支持情况独立取证。明确结构请求直接校验，只有无法确定性解释的自然语言部分考虑局部模型。

### 具体语义请求与预期结果（不是编码Schema）

| 请求 | 预期 |
| --- | --- |
| scope=A；subject=op:42；fact=signature；expand=无 | 顶层签名及必要类型引用；已存body标未展开/已获取，不返回body |
| scope=A+B；name=run；候选A/run、B/run | 该项歧义，列定位；另一个唯一subject=type:7可独立完成，总体部分/需澄清，不猜共同项目 |
| op:42；context target=缺失，而条件分别为T1/T2 | 适用解释未定，保留条件与缺口；不能选T1或合成冲突 |
| op:42查询x/y/z；x已获取但未展开且冲突，y不适用有依据，z工具超时 | x保留呈现/获取/冲突维度，y不适用，z未满足且超时；总体部分，零适用不等不存在 |
| A含B，B含A；授权contains方向正向深度3 | 深度1=B，2=A引用/回环标记，3=B引用；定义不重复，有限遍历不提前吞掉明确授权 |
| A经p到S余深度0，经q再r到S余深度1，q/r授权另含child | 两路径各自按余深度与授权处理；第一路径未展开不能阻止第二路径合法child展开 |

总体完整成功仅当全部请求项满足所需语义证据；任一不满足且有可用项为部分，无可用项则失败/需澄清，终止原因另列，逐项信息始终保留。冲突满足“查询冲突主张”的请求可成功，但不满足“确定唯一值”的请求。


## Risks / Trade-offs

投影表不完整将阻塞具体字段验收，必须随#3目录冻结；图环/共享组成不能误变所有权；诊断/证据载荷须审查不绕过投影；不以歧义要求用户批准所有已明确项。

## Migration Plan

只规划；不改正式主规格、不apply、不archive。先冻结公共定义和未决重大选择，再整体审核，最后取得明确开发批准。唯一任务清单为本变更tasks.md，不维护第二套Superpowers计划。语言/混合边界、host和target按#5/#10矩阵取证；#5定义质量、端到端延迟/吞吐/资源及Token评价，数值未定不得宣称达标。
