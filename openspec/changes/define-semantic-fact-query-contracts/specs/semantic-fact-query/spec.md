# semantic-fact-query

## ADDED Requirements

### Requirement: 规范请求不静默扩大
系统 SHALL 保留项目选择、主体或选择器、所需事实/关系、上下文及展开边界；不能唯一解释时披露候选和歧义，不静默选定或全返。

#### Scenario: 同名操作跨项目
- **WHEN** 名称同时匹配两个项目中的操作
- **THEN** 只返回歧义及候选定位，依赖该选择的获取不执行

### Requirement: 逐项结果保留独立状态
系统 SHALL 逐项保留呈现、获取、适用、有效性、覆盖和诊断语义，总体部分/失败不能吞并项级缺口；不存在须有范围及否定证据。

#### Scenario: 混合结果
- **WHEN** A满足请求而B能力不支持
- **THEN** 分别报告并将总体标为部分，B不能变不存在或完整成功

### Requirement: 展开图有界且不夹带
系统 SHALL 按显式关系方向与深度控制跨边展开，根为0；循环终止并保留引用，不通过值、证据或诊断内嵌定义绕过范围。

#### Scenario: 组成存在循环
- **WHEN** 用户限定组成关系深度1且图有返回根的路径
- **THEN** 只跨允许的一条边，后续保留引用而不递归构造响应定义
