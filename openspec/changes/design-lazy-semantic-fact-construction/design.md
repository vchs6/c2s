# Design

## Context

已确认：共享context、ADR-0001至0007及对应正式规格；模型A由用户选择但未批准实施。当前无产品实现或性能实测。新设计是候选；细节由授权范围内代理提出，不成为用户确认。讨论、异议及独立复核见本Issue评审目录。

## Goals / Non-Goals

无查询不构造具体语义；查询只补必要缺口、按适用性和有效性复用。非目标：语句级粒度专项、后台预构造或无限语义闭包。

## Approaches

候选需求图缺口规划：复用有效事实，再按依赖理由补足；替代按查询完整重算所需对象，协调简单但重复Token；二者按#5同质量比较，不以热命中推断冷收益。提前全仓语义预计算不满足用户按需目标。

## Decisions

输入为#7规范请求、模型A目录/投影规则与可用来源能力；输出有界需求计划、已有有效事实和未解决缺口。计划节点以主体/谓词需求、条件、来源依据、规则版本和能力边界区分；不是创建新的主体身份。请求与内部工作、最终响应分别限定；响应展开深度不能作为内部必要语义依赖的上限。

未查询时不预构造全目录具体语义；必要环境/工具探测及定位由设计安排，不因此提前构造所有E0–E4事实；不得把全仓行为事实称为索引绕过按需。已存在的工具索引可消费，新增索引范围/成本由请求需要证明；不隐含后台watch或定时构造。

| 请求例 | 必要工作 | 不执行 |
| --- | --- | --- |
| 项目概览 | 定位工程声明和边界依据，取所需顶层事实 | 全部操作body |
| 单操作契约 | 读取该操作及影响契约的必要声明/调用条件 | 无理由全仓算法 |
| 明确局部算法 | 取得所指局部及必要引用证据 | 默认逐语句事实化或展开所有被调用者 |

停止条件：需求已有有效且适用事实；必要缺口由能力明确不能取得；依赖循环在同需求/上下文/规则上无新增信息；或请求取消、资源限额/超时。循环不推不存在，无法穷尽的跨项目/混合语言边界报告覆盖缺口。限额由代理设计并在实际测试中记录调整，不以限额结束伪完整。新依赖必须附必要性理由且仍在请求授权的分析边界，越界需澄清或保留缺口，不能无界扩取。

计划状态仅内部处理：待满足→可复用/待获取→经校验候选/未满足/取消；公共获取、呈现、有效性、诊断沿用模型A/#7，不拿内部done代替语义成功。获取失败可保留已校验部分与未完成项；取消本请求不再新调度，单订阅退出不终止其他订阅所需共享工作；取消后的成果仅在独立核验且满足发布政策后可复用，已发生提交的可见性与幂等由#9/#12定义。并发相同需求由#12合并执行，本能力仅输出可比较需求键，不重复实现锁。

相同源码结构化解析/证据跨层复用，模型只接确定性转换后必要未解决语义；缺工具或条件不明时报告缺口，不用LLM猜作确定事实。单次分析项目固定（ADR-0006），只复用属于本分析且条件/能力/覆盖适用的成果；不从项目固定推断未知契约已满足。
复用须同时匹配模型A主体身份、来源版本及有效性、配置、host/target适用、工具能力/规则版本与覆盖需求；不能单凭源码相同。核验成本纳入#5与局部重提对照。需求键去重须保留不同上下文和必要依赖；最后订阅退出由#12定义执行停止，发布政策未定时不将取消后候选标可复用。


## Risks / Trade-offs

局部依赖漏检将低估Token且损质量：记录覆盖边界/闭包未定；需求循环与主体环不同，#7只解释本次请求目标并投影顶层，不承诺对外深度/路径参数；首次定位开销进入#5计量，不隐藏在初始化。

## Migration Plan

只规划；不改正式主规格、不apply、不archive。先冻结公共定义和未决重大选择，再整体审核，最后取得明确开发批准。唯一任务清单为本变更tasks.md，不维护第二套Superpowers计划。语言/混合边界、host和target按#5/#10矩阵取证；#5定义质量、端到端延迟/吞吐/资源及Token评价，数值未定不得宣称达标。

## Open Questions

工具/Skill前置接续：#10新增调研报告与矩阵为本能力配置来源。按需计划可调用符合契约的分析Skill或底层接口；预算/Top-k只是检索，需识别分页/省略/无内容与失败，补全当前所需顶层事实或明确缺口。底层扫描/解析/结构索引/具体语义构造分开判断，必要全目录盘点不等全语义预构造，但索引不能自动豁免按需约束。候选默认忽略和自动watch不改变用户范围及固定项目前提。接口完整性/索引内容映射未验证，当前不据调研报告宣称组合可运行。

需由代理落实能力配置、请求相对顶层投影规则、工具对依赖发现的完备性。不能据候选流程宣称低延迟或Token减少比例。

增量边界：同次分析固定项目输入，查询可以不断增加所需事实；无需来源变化失效传播或热更新。跨次输入更新/复用未由用户本句确认，另留讨论，不阻塞本期同次需求计划。

## ADR-0007查询驱动补充

用户查询指定目录中的语义事实时，尚未取得内容即针对该请求开始分析，不要求预先全目录扫描构造。相同主体后续只补本次未完成项；已完成且适用成果复用，但不能只返回缓存中已有少数项而漏当前所需顶层事实。缺口及原因交#7同源生成报告与结构数据。目录内全部内容均在范围，必要内部定位/取证可以覆盖相关文件，不等于递归呈现或提前构造全目录事实。
