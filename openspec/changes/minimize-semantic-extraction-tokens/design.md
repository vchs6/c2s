# Design

## 当前领域模型基准

当前领域模型基准：成本按请求所需的语义实体、属性/关系、实现/验证映射、证据及覆盖变化测量；确定性源码构造解析与语义解释分开计量。E0–E4可供分层报告，不作为构造器的实体分类或需求完成单位。

## M1模型参与与计量消费（代理技术决定，m1-project-discovery-1）

本切片仅明确元数据、工程边界评估规则和原生成员，采用#10确定性直转、#8复用/补缺、#9确定性去重、#7同源双输出。相较整包代码图交模型再转JSON，省去可机械完成的模型工作；这是待测机制，不是已实现或节省率声明。ADR-0009授权/独立门禁继续适用，不等全部M3算法语义/全部候选工具冻结。

本节独占M1ModelDecision={needId:Id,mode:"deterministic"|"unavailable",reason:string,evidenceIds:Id[],diagnostics:M1Diagnostic[]}，端口`decide_model_m1(need:M1Need, acquired:M1Acquired)->M1ModelDecision`。可确定转换为deterministic；能力缺口为unavailable并报告原因，M1不以模型猜项目归属、语言全集、成员或否定来填洞；自然语言固定短语解析也不调用模型。本切片不定义未使用的通用LLM上下文包；后续语义查询另行设计，不扩大本次范围。

实际计量唯一复用#5 M1Usage/M1Profile/compare_m1；#12/#10报告所有调用（包括工具/Skill内部调用，未知记unknown），不能因本策略“不主动调用”推整个上游成本为零。已知未调用的确定性路径usage=[]，与“无法观察调用量”区分。冷/复用/补缺/失败全链事件都计，不通过重算报告/结构数据重复读源码。前后比较只消费#5含factSummary/逐项gaps/strategyId的自包含Profile，正常化/open失败也保留成本；不同inputId/identityDomain明确不可比，不按路径/名称重配主体，不读全局缓存补数据。复用只消费#12 current_m1有效叶；旧失败仍计入事件成本而不永久当当前缺口。成功提交后以规范重读内容投影一次，失败保留已校验暂存；不另定义Token数/成功口径，未测不冻结收益。


## Context

历史背景：原提案以共享context、ADR-0001/0002及当时五视角主规格为约束，并记录用户对模型A的历史选择。当前领域主轴按ADR-0012更新为语义实体；本段未实现的模型细节/性能候选不因本次对齐自动成为用户确认。讨论、异议及独立复核仍见本Issue评审目录。

## Goals / Non-Goals

在固定语义、正确性和证据约束下最小化实际输入/输出Token；非目标：只设限额、所有场景零Token、压缩掉必要事实或改变事实粒度。

## Approaches

候选确定性优先、按缺口局部模型与有效成果共享；替代每个请求对其所需源码直接模型分析，流程简单但重复输入输出；另一个可行替代是工具结构结果整包给模型统一转换，适配工作少但将确定性可转换内容重复交模型。都需相同输入/请求范围的前后对照，不先声称一种必然更省或更快。

## Decisions

| 阶段 | 不需要LLM的工作 | 必要模型边界 |
| --- | --- | --- |
| 请求 | 结构请求校验/选择器路由 | 可选自然语言歧义解释，仅必要片段 |
| 定位/获取 | 文件定位、工具结构输出、版本配置核验 | 工具不能确定且请求必需的语义解释 |
| 分层构造 | 目录驱动转换、共享证据/结构、条件机械校验 | 缺口问题+相关局部代码+必要依赖，不按层重读 |
| 存储/复用 | 规范比较、去重、差量、适用/有效性核验 | 不用模型判同或决定覆盖 |
| 响应 | 有界投影、状态/引用序列化 | 只有请求确需且无法确定性呈现的解释，不重复生成全部事实 |

| 优化 | 省去的模型工作 | 保持内容与失效条件 |
| --- | --- | --- |
| 结构直接转换 | AST/元数据整包语言化再解析 | 保原始证据、模式/条件/覆盖；工具局限/配置不符则不宣称等价 |
| 实体来源复用 | 同一源码构造/证据被多个实体请求重复解析或提供 | 共享来源不表示实体属性、关系或映射已取得；仍按实体请求补足相应覆盖 |
| 有效事实复用 | 重复请求重提/重生成 | 核全部适用条件/来源/能力规则版本覆盖；变化或未核验不复用为当前有效 |
| 需求差量 | 后续查询再全仓/全层重分析 | 项目固定，按有证需求图只补尚未取得内容；依赖不明保缺口，不等于无需必要语义 |
| 必要上下文包 | 整仓源码及重复提示/输出 | 包含问题、身份/上下文、最小相关证据、规则和缺口；缺必要依赖时请求有界补取或部分，不猜完整 |
| 分阶段成果复用 | 存储失败后再次模型构造 | 经核验成果在有效性与发布条件仍成立时重用，否则重建；重试成本不隐藏 |

输出只需新增主张及证据引用/局限，而非反复回显已知公共目录和整包旧事实；引用必须可解到保留内容，不把证据丢给不可复现外部链接。模型输出每次经公共契约/来源核验，核验失败和重试成本算入总量。共享提示前缀或供应商缓存仅辅助，不能以账单折扣代替实际输入输出Token下降。

验证设计沿用#5：同输入快照/请求/实际取得内容/缺口报告口径/语言host-target/模型版本，先选优化前后两个版本比较；需要定位机制贡献时，可额外拆分必要上下文直模、直转局模和共享增量组，不把三组/四组全部实验设为当前业务前置。不得故意将直模输入膨胀为无关全仓来制造收益；比较时同时列实际取得事实与缺口变化，不要求严格语义正确性证明；漏取所需顶层内容或隐藏缺口不得包装为收益。分别首次构造、同次重复复用、后续查询补充、失败重试；每一项机制做移除对照以归因。报告总/输入/输出Token、调用数、模型源码/上下文量、重复分析、质量/覆盖及端到端延迟/资源。固定请求不比较每事实比率，账单/缓存计费另列；未测或失败如实列不挑成功样本。

向#6回补职责不增加新模型服务：#10产生可转换结构与局限，#8规划复用/差量需求，#9确定性保存，#12协调有效性和失败恢复，#7确定性投影；本能力只拥有模型参与策略/上下文包与对照归因，避免重复实现其他能力。

预算、调用上限、退避与超限只停止不可承受工作并报告缺口；不当作优化机制。正确性/覆盖不能为降Token自动降低。若满足质量的候选比对照更多Token或更慢，保留测量，重大取舍提交用户，不宣称最优或隐藏成本。

## Risks / Trade-offs

确定性适配/核验也消耗CPU时间和维护成本；局部上下文可能漏非局部语义，需反例和必要补取。需求依赖图不完备不能假装差量正确。Token优化不自动意味着延迟改善；无测量不冻结收益比例。

## Migration Plan

只规划；不改正式主规格、不apply、不archive。先冻结公共定义和未决重大选择，再整体审核，最后取得明确开发批准。唯一任务清单为本变更tasks.md，不维护第二套Superpowers计划。语言/混合边界、host和target按#5/#10矩阵取证；#5定义质量、端到端延迟/吞吐/资源及Token评价，数值未定不得宣称达标。

## Open Questions

工具与Skill调研接续：#10的24份一手资料及矩阵已补项目分析/图谱Skill。组合比较包括直接结构接口、高层Skill成果及必要模型转换，不规定先工具后Skill；满足契约的Skill可直接供事实来源。实际Token账包含Skill指令、内部模型/嵌入/重试、分页补取与后续解释；索引CPU/时间/磁盘另列，无法观察的内部成本记unknown。上游短预算、context_savings或基准宣传不当本项目收益，不能通过遗漏顶层所需事实取胜；所有候选仍未实测，必须按#10试验任务取得证据再冻结具体优化组合。

代理需继续落实工具能力、报告口径和模型策略并提交整体设计审核，不再等待用户给严格金标或数值目标。若实测出现质量/延迟/Token冲突，新增具体用户决策而非自动改变基线。

ADR-0006固定项目输入下，增量主要是需求/事实增量，不要求源码编辑后的失效传播或跨次更新。若未来另行做不同项目输入之间的变化对照，须标为独立分析，不作为本期功能前置；仍不得用不适用输入成果省Token。

ADR-0007：当前一层是符合请求要求的顶层语义事实，“最小上下文”不能变成删减本次顶层所需事实；用户同时需要报告和机器数据，复用同一结果而不是让模型分别重新分析两遍。性能/Token由代理优化前后实测对照，如实报告，不能通过计量/限额替代减模型工作。

## ADR-0013 当前约束（2026-11-08）

比较同一输入和请求下的事实、证据及缺口，再比较冷索引、工具执行、模型和重复查询成本；不得靠省略算法、来源或未解决项取得表面收益。 依据：`docs/decisions/0013-非DDD语义事实模型.md`。历史执行记录中的DDD或旧模型表述不构成现行约束。本轮只进行文档修订，产品重构完成状态不变。
