# Design

## Context

ADR-0013及修订规格已生效。现有实现仍有冷实体查询全仓构造、实体类型固定映射视角、来源组织缺少独立持久查询和粗粒度复用等差距。旧实体模型实现与兼容切换记录保留在第1–9节历史任务，不作为本轮完成证据。

## Goals / Non-Goals

保留上游组织、语义实体、源码实现和算法/测试参考，统一来源证据、细粒度覆盖及按需查询。首期Rust/Python，不输出迁移方案或设计评价，不增加DDD/六边形强制架构。

## Decisions

完整规范设计唯一维护于[非DDD事实提取重构设计](../../../docs/superpowers/specs/2026-11-08-非DDD事实提取重构设计.md)，执行前必须读取全文。该文档包含组件差距表、方案取舍、v2数据协议、精确接口、持久化与故障、兼容回滚和验收口径。

采用现有项目渐进重构，新增v2档案以避免在封闭v1协议内暗加字段；显式选择验证后才切换默认。原生解析/算法/SQLite继续复用；CodeGraph仅为按实际覆盖收益选择的可选适配器，不改变基础工具必需栈。

## Risks / Trade-offs

新增profile增加兼容成本，但可独立验证和回滚；按需计划若漏依赖必须显式保留gap；代码图无完整枚举或新鲜度证据时只输出候选。实际成本、平台及词元收益由实测决定。

## Migration Plan

按本目录tasks第10节执行：契约→来源组织→请求计划→按目标构造→原子存储→可选图适配→统一查询→兼容迁移→真实项目集成→默认切换。任务自身携带测试和文档，最后只做跨组件集成及切换验证。未有对应任务证据时不切换、不归档。

## Open Questions

无新增产品范围未决项；具体技术选择见规范设计并接受构建可行性审核。当前只交付设计与任务分解，没有执行本轮产品实现。
